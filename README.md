# 🏔️ Alpine Ascents

Alpine Ascents is a responsive mountaineering and adventure website designed to provide information about mountain climbing, techniques, expeditions, records, sheltering, organizations, stories, gallery, updates, guidelines, and contact information.

The project focuses on a clean, modern, and professional mountain-themed design with a responsive layout for different screen sizes.

---

## 🌐 Live Website

🔗 **Live Demo:**  
https://rubab11a.github.io/Alpine-ascents/

---

## 📌 Project Overview

Alpine Ascents is a complete multi-page website created as an Aptech e-project.

The website provides users with an interactive platform where they can explore different aspects of mountaineering, including:

- Mountain climbing
- Climbing techniques
- Mountain records
- Sheltering and camping
- Mountaineering organizations
- Mountain stories
- Image gallery
- Latest updates and news
- Safety guidelines
- Contact information
